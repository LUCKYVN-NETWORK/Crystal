# Crystal

## Generated block API (for external plugins)

Crystal exposes a Bukkit service so other plugins can check if a block was generated by Crystal:

- Service type: `me.stella.marker.GeneratedBlockMarkerService`
- Helper access: `me.stella.api.CrystalApi#generatedBlockMarkerService()`

Example:

```java
import me.stella.api.CrystalApi;
import me.stella.marker.GeneratedBlockMarkerService;
import org.bukkit.block.Block;

public boolean isCrystalGenerated(Block block) {
    return CrystalApi.generatedBlockMarkerService()
            .map(service -> service.isGenerated(block))
            .orElse(false);
}
```

## Persistence model

- Generated markers are saved in each chunk's `PersistentDataContainer`.
- Markers survive plugin reloads and normal server restarts.
- Markers are automatically cleared when blocks are placed/broken/exploded/moved by pistons/overwritten by fluid.
